# HORAS RASA

Website statis HTML, CSS, JavaScript.

1. Ekstrak ZIP.
2. Buka index.html untuk melihat website.
3. Unggah seluruh isi folder ke repository GitHub (index.html harus di root).
4. Di Vercel, import repository, pilih Framework Preset Other, tanpa build command, lalu Deploy.

Katalog 20 menu; visual sajian berbantuan AI. Harga, ketersediaan dan sertifikasi halal belum diverifikasi. Proyek tugas kuliah Strategy Brand Communication, Ilmu Komunikasi UNDIRA.
